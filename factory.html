La clé est envoyée uniquement à l'endpoint HTTPS de ce projet. Ne la partage jamais dans un message ou une capture d'écran.

02 — Nouveau site

Les nouveaux dépôts sont privés par défaut. La console ne propose pas de création publique.

Aucune création lancée.

Comment ça fonctionne

  1. La Factory vérifie la clé et la configuration serveur.
  2. Elle crée un dépôt GitHub privé et ajoute une page de départ.
  3. Elle demande à Netlify de connecter le dépôt dans l'équipe configurée.
  4. Le premier déploiement démarre automatiquement si les autorisations sont correctes.

La vérification de configuration contrôle la présence des variables, pas encore la validité réelle des autorisations GitHub et Netlify.
